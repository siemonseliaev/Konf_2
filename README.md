# Эмулятор Virtual File System (VFS) — Этап 2: Конфигурация

Графическое приложение на Python (Tkinter), эмулирующее работу командной строки для взаимодействия с виртуальной файловой системой (VFS) с поддержкой параметров конфигурации и стартовых скриптов.

## Особенности

* **Гибкая конфигурация:** Прием аргументов командной строки для указания пути к VFS и стартовому скрипту с помощью `argparse`.
* **Отладочный вывод:** Вывод параметров конфигурации в консоль приложения при запуске.
* **Автоматическое выполнение скриптов:** Выполнение команд из текстового файла по порядку с имитацией ввода пользователя.
* **Устойчивость к ошибкам:** Обработка синтаксических ошибок (например, незакрытых кавычек) без прерывания работы приложения или выполнения скрипта.
* **Графический интерфейс:** Интерфейс в стиле терминала на Tkinter с динамическим приглашением ко вводу.

##Параметры командной строки

 `vfs`  `str`  `my_vfs.tar`  Путь к физическому расположению VFS файла 
 `script` `str`  `None`  Путь к стартовому текстовому скрипту с командами

## Поддерживаемые команды

 `help`  —  Вывод справки по доступным командам 
 `ls`   Вывести список файлов (принимает множество аргументов)
 `cd`   Сменить директорию (требует ровно 1 аргумент) 
 `exit`  —  Завершить работу приложения
